Data sources & settings

How the data works (honest version)

  • No key (default): quotes come straight from CNBC’s public quote service (no relay). They may be slightly delayed.
  • Finnhub (recommended for reliability): free account, 60 calls/min. Calls Finnhub directly (it allows browser requests), no proxy. Sparklines still try Yahoo; if that fails they stay blank.
  • Alpha Vantage: free key but only 25 requests per day, so it’s a last resort and auto-refresh will burn through it fast. Quotes are typically end-of-day/delayed.
  • TradingView widgets (ticker tape, chart, headlines, fallback quote cards) use TradingView’s own data and never need a key. They can’t feed the portfolio math.
  • Auto-refresh runs every 10 seconds while this page is open, during pre-market, regular and after-hours sessions (Mon–Fri 4:00 AM–8:00 PM ET). It pauses when the page is hidden and refreshes as soon as you come back.

Get a free Finnhub key (2 minutes)

  1. Go to finnhub.io/register and sign up (free plan).
  2. Copy the API key from your dashboard.
  3. Paste it above, leave source on Auto, click Save & refresh.

Alpha Vantage key: alphavantage.co/support/#api-key. Keys are stored only in this browser’s localStorage on this computer.
